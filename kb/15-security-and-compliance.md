# Security and compliance

- **SOC 2 Type II**: a current report is available under NDA. Request it from
  security@harbordesk.example; we return the NDA the same working day.
- **GDPR**: we act as processor. A signed Data Processing Agreement, including standard
  contractual clauses, is available from Settings → Legal → DPA.
- **Data location**: EU customers are hosted in eu-central-1, all others in us-east-1. The
  region is fixed at workspace creation.
- **Encryption**: TLS 1.2+ in transit, AES-256 at rest.
- **Sub-processors**: listed at harbordesk.example/subprocessors, with 30 days' notice of
  changes.

Suspected data exposure, or any case where one workspace can see another's data, is treated as
a P1 incident. Contact security@harbordesk.example and we respond within one hour, 24/7.
