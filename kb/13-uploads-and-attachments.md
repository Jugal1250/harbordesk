# File uploads and attachments

Supported file types: JPG, PNG, HEIC, PDF, DOCX, XLSX and CSV.

The **maximum file size is 10MB per attachment**. Files above the limit are rejected by the
upload service. On slower connections the browser may show the spinner for some time before
the rejection is reported, so the upload can look as if it is still running.

Tips for field photos:
- Enable **Compress photos before upload** under Settings → Mobile. Most phone photos then
  land between 1 and 3MB.
- Up to 20 attachments per job.
- Attachments are retained for as long as the job exists, and are included in account exports.
