# Exporting your data

**CSV export**: open any list view, apply your filters, then select **Export → CSV**. The
export contains the columns currently visible in the view. Columns you have hidden are not
included, which is the usual reason a column looks blank in the file but populated in the app.
Add the column back to the view, then export again.

**Full account export**: Settings → Data → **Request export**. We build a ZIP of every record,
attachment and audit entry and email a download link, usually within an hour. The link is
valid for 7 days. This is the export to take before cancelling.

Exports are available to Admins only and every export is recorded in the audit log.
